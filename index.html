关于潮汐音乐 關於潮汐音樂 About Tide Music

潮汐音乐 · Tide Music 是一个完全运行在浏览器中的音乐门户，无需安装任何软件，打开网页即可使用。

它集成了：

  • 🎵 本地音乐播放（支持多选导入）
  • 🌐 网络音频地址直接播放
  • 📝 LRC 歌词解析与逐行同步高亮
  • 💫 基于 Web Audio API 的实时节拍律动
  • 📻 网络收音机（分类、收藏、自定义添加）
  • 🎚️ 收音机指针随音频实时摆动
  • 📌 首页迷你播放控制条（音频播放时可见）
  • 🌏 多语言界面（简体中文 / 繁体中文 / English）

所有数据仅保存在你的浏览器本地，收藏的电台会通过 localStorage 持久化，不会上传到任何服务器。

Tide Music is a music portal that runs entirely in your browser — no installation, just open and enjoy.

It includes:

  • 🎵 Local music playback (multi-file import)
  • 🌐 Direct URL audio playback
  • 📝 LRC lyrics parsing with line sync
  • 💫 Real-time beat visualization via Web Audio API
  • 📻 Internet radio (categories, favorites, custom add)
  • 🎚️ Radio needle swings in real-time with audio
  • 📌 Home mini player bar (visible when audio plays)
  • 🌏 Multi-language UI (简体中文 / 繁體中文 / English)

All data is stored locally in your browser. Favorites persist via localStorage and are never uploaded.
